# Linux 两次精简体验

总计 6 小时，每次 3 小时。目的只是补齐常用开发工具和线程基础，不制作 Linux 求职项目，也不在 11 月前切换主线。

| 次数 | 内容 | 必须输出 |
|---|---|---|
| 1 | WSL2 Ubuntu、目录和权限、GCC、Makefile、GDB 断点/单步/调用栈 | 一个 Makefile 构建的多文件 C 程序；一份用 GDB 定位越界或空指针的记录 |
| 2 | POSIX 线程、共享变量、竞态和互斥锁 | 一个双线程计数程序；修复前后结果；用自己的话解释为什么需要互斥锁 |

每次结束只记录：命令清单、运行截图或日志、踩过的坑、是否愿意以后深入。TCP/UDP、驱动、内核和网络项目全部推迟到本轮求职结束后。
