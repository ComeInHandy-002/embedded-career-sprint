# 项目一：STM32 裸机传感器记录器

目标硬件：NUCLEO-F446RE、BME280、I2C OLED。截止日期：2026 年 9 月 13 日。

本目录只定义需求和验收，不提供核心实现。STM32CubeIDE 工程必须由你自己新建。

## 固定功能

- 使用 I2C1 每秒读取一次 BME280。
- OLED 每 500 毫秒刷新温度、湿度、气压和报警状态。
- USART2 通过板载虚拟串口提供非阻塞 CLI。
- 使用定时器或系统节拍安排任务；初始化完成后禁止依赖长时间阻塞延时。
- 环形缓冲区保存最近 60 次有效采样。
- 连续 3 次读取失败后标记传感器离线；连续 2 次成功后恢复在线。
- 默认高温阈值 30.0 摄氏度、湿度阈值 80.0%，允许通过 CLI 修改。

## CLI 对外接口

| 命令 | 行为 |
|---|---|
| `help` | 显示命令列表 |
| `status` | 显示当前数据、在线状态、报警位和错误计数 |
| `threshold get` | 显示当前温湿度阈值 |
| `threshold set temp <整数>` | 修改温度阈值 |
| `threshold set hum <整数>` | 修改湿度阈值 |
| `history <1-60>` | 输出最近指定数量的有效采样 |
| `errors clear` | 清除累计错误计数，不改变当前在线状态 |

非法命令必须返回明确错误，不能导致死循环或越界。

## 分层结构

```text
Core/       CubeIDE 生成的启动和 HAL 入口
Bsp/        引脚、I2C、UART、定时器等板级封装
Drivers/    BME280、OLED 等器件驱动
App/        采样、报警、CLI 和调度逻辑
Utils/      环形缓冲区、错误码、字符串解析
Docs/       接线、模块图、测试与演示说明
```

`main.c` 只负责初始化和调用应用循环，不允许堆放全部业务逻辑。
