## 环形缓冲区任务

已经提供：

- `include/ring_buffer.h`：接口和数据结构。
- `src/ring_buffer.c`：可编译但没有实现逻辑的骨架。
- `tests/test_ring_buffer.c`：8 个自动测试。
- `run_tests.ps1`：Windows 下一键编译和运行测试。

你需要独立完成 `src/ring_buffer.c` 中的所有 `TODO`。不要改变公开接口，也不要为了让测试通过而删除测试。

运行方式：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_tests.ps1
```

为了避开部分 MinGW 版本对中文输出路径的兼容问题，脚本会把临时测试程序生成到 Windows 临时目录；源码位置不会改变。

通过标准：8/8 测试通过，GCC 没有警告；随后不看源码画出 `head`、`tail`、`count` 在回绕时的变化。
