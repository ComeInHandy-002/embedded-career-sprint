### 环形缓冲区状态口诀

```text
push: 写 data[tail]，tail 后移，count + 1
pop : 读 data[head]，head 后移，count - 1
peek: 读 data[head]，不改 head、tail、count
empty: count == 0
full : count == RB_CAPACITY
```

## 1. 四大核心概念：变量、地址与指针的物理映射

在C语言的内存世界里，你需要彻底弄懂以下四个概念的区别：

* **`int value`（变量的值）**：变量就像是内存里的一个小盒子，里面装着具体的真实数据（比如数字 10）。


* **`&value`（取地址符 `&`）**：`&` 是取地址符，它能获取到这个小盒子在内存中具体的位置（比如 101号房间）。


* **`int *pointer`（指针变量）**：指针本身也是一个变量，但它里面存的不是普通数据，而是别的变量的**内存地址**。


* **`*pointer`（解引用符 `*`）**：`*` 是解引用符。它代表**通过地址访问那块内存**，去读取或修改目标房间里的真实数据。



**💡 终极一句话口诀**：


`x` 是值，`p` 是地址；`&x` 是取地址，`*p` 是通过地址访问那块内存。

## 2. 生活中的比喻：为什么不能“只换纸条”？

初学指针最容易犯的错，就是混淆了“指针本身”和“指针指向的数据”。假设 `left` 和 `right` 是你手里的两张**纸条（指针）**，上面分别写着“101号房间”和“102号房间”的地址；而房间里真正住着的数字，就是**真实数据**。

* **只操作指针（`left = right;`）**：这仅仅是把你手里纸条上的字擦掉互换了一下，改变的只是局部指针本身的朝向，毫无意义，房间里的真实数据根本没有挪动半步。


* **解引用操作（`*left = *right;`）**：跨越了纸条，直接打开了房间门！这样才能精准交换外部内存中的真实数据（全局生效，一击必杀）。

## 3. 为什么要用指针？（跨作用域修改）

在 C 语言中，函数参数默认是**值传递**的。当外界把变量传进函数时，系统其实只是“复印”了一份数据交给你，函数一旦执行完毕，复印件就会被销毁，外部的真实世界依然纹丝不动。

因此，**如果函数想修改外部变量，必须传地址进来（例如 `d2_swap_int(&a, &b)`）**。只有拿着地址，函数才能跨越作用域，直接修改调用者内存里的值。

## 4. 绝对的铁律：进门查空

既然指针手里拿着别人给的“地址”，那么在使用这个地址（解引用 `*`）之前，必须做一件事：**防非法输入**。
指针参数在使用前，必须用 `if (ptr == NULL)` 判断是否为空。如果不做这个安检，一旦遇到空地址（`0x0`），操作系统会毫不犹豫地判定为“段错误（Segmentation Fault）”并立刻让程序崩溃。
