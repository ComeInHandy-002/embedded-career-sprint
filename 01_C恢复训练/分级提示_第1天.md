# 第 1 天分级提示

每个函数至少独立思考 20 分钟。只在确实卡住时逐级展开，不要一次读完。

## `d1_sum`

### 第一级：自问

- 哪两个指针必须有效？
- 长度为 0 时，这个练习是否允许成功？请从测试和接口注释判断。
- 如何保证失败时不修改 `sum` 原来的值？

### 第二级：算法方向

先验证参数，再用局部变量累计每个元素，遍历结束后才写入输出指针。

### 第三级：伪代码

```text
如果必要指针无效：失败
局部总和设为 0
从第 0 个元素遍历到 length - 1
    累加当前元素
把局部总和写给调用者
成功
```

## `d1_max`

### 第一级：自问

- 空数组是否存在最大值？
- 数组全为负数时，候选最大值应该从哪里开始？
- 正常输入至少要访问几个元素？

### 第二级：算法方向

参数有效且长度非零后，用第一个元素作为候选值，从第二个元素开始比较。

### 第三级：伪代码

```text
如果指针无效或长度为 0：失败
候选值设为第一个元素
遍历剩余元素
    如果当前元素更大：更新候选值
成功后写入 maximum
```

## `d1_reverse`

### 第一级：自问

- 是否允许创建第二个等长数组？
- 两个下标分别从哪里开始？
- 空数组和单元素数组是否需要进入交换循环？

### 第二级：算法方向

用左右两个下标交换元素，每次左边加 1、右边减 1；只有左边仍在右边之前时才继续。

### 第三级：伪代码

```text
如果数组指针无效：失败
如果长度小于 2：直接成功
左位置设为开头，右位置设为末尾
当左位置在右位置之前
    交换两个位置的值
    两个位置向中间移动
成功
```

## `d1_count_equal`

### 第一级：自问

- 计数初始值是多少？
- 没有匹配项和非法输入都返回 0，调用者是否能区分两者？这是当前接口有意接受的限制。
- 每次遇到目标值要改变哪个变量？

### 第二级：算法方向

非法输入直接返回 0；否则遍历数组，每次匹配就增加局部计数，最后返回计数。

### 第三级：伪代码

```text
如果数组指针无效：返回 0
计数设为 0
遍历所有元素
    如果当前元素等于目标值：计数加 1
返回计数
```

## `rb_init`

今天只做初始化，不继续写 `push`、`pop`。

### 第一级：自问

- 哪个参数可能为空？
- 初始化后的 `head`、`tail`、`count` 应分别是什么？
- 初始化成功和参数非法分别返回哪个枚举值？

### 第二级：状态方向

先拒绝空指针，再把三个状态字段恢复到空缓冲区的起点。数据数组不需要清零，因为 `count` 决定哪些元素有效。

### 第三级：伪代码

```text
如果 buffer 无效：返回非法参数
把 head、tail、count 设为空状态
返回成功
```
