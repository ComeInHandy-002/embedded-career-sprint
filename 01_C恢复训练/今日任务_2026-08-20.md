## 读取接口的边界条件

实现前先写出以下判断顺序，不要直接照抄完整实现：

- `rb_pop`：`buffer == NULL` 或 `value == NULL` 返回 `RB_INVALID_ARGUMENT`；空缓冲区返回 `RB_EMPTY`，且不能修改 `*value`；成功时读取 `data[head]`，移动 `head`，减少 `count`。
- `rb_is_empty`：空指针按空处理；正常情况下判断 `count == 0U`。
- `rb_peek`：参数和空状态检查与 `rb_pop` 相同；成功时只读取队首，不移动任何下标，也不改变数量。

下标移动要使用与 `rb_push` 对称的回绕表达式：

```c
(index + 1U) % RB_CAPACITY
```
